The LiKeMi static website has moved beyond its initial structure test and is now maintained
as a public information archive. Announcements, news, and introductory material are stored
as Markdown and published through a static build.

## Maintenance Rules

- Chinese and English counterparts use the same filename.
- `publishDate` records first publication. Corrections should not change it merely to make
  an old article appear new.
- Historical news keeps the context in which it was written.
- External images and links should be checked periodically and replaced with durable project
  assets when possible.
- Drafts and placeholder copy must not appear in the public article list.

To report an error, include the page URL, location, and supporting source. Privacy, security,
or account incidents should be sent privately to maintainers rather than discussed publicly.
