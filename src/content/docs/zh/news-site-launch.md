## 一个稳健的新起点

官网这次采用更稳健的方式重建上线。经历过一次不愉快的删库事故后，我们把“写内容 →
发出去 → 不丢”想成了整条链：页面与文档在构建时生成静态文件，直接提供给访客；图片等
素材作为静态资源随站点发布；资料以 Markdown 集中管理；关键目录另做一份远程落盘。哪怕再
出意外，也能很快回到正轨。

新版也顺手把入口理顺——首页介绍、延伸资源、团队与文档都收敛到一个清楚的层级里，少了
以前“东西散落、半天找不到”的焦躁。

## 这次重建改了什么

最直接的变化是内容与页面分离。文章不再散落在临时页面或聊天记录里，而是以 Markdown 文件
保存在仓库中，由构建过程统一生成页面。这样做的代价是发布前多一道检查，换来的是可追溯、
可备份、可回滚。

站点结构也重新划分：首页负责定位与近期更新，`/news` 负责按时间浏览，文章页负责长期阅读，
团队与资源页负责组织信息。每个入口只做一件事，导航因此比旧版更短。

## 阅读体验

文章页增加了右侧阅读目录，标题来自正文中已渲染的二至四级标题；滚动时目录会跟随高亮当前
章节。列表页支持搜索与标签筛选，文章顶部显示发布日期和大致阅读时长，文末可以按顺序继续
读上一篇或下一篇。

移动端与桌面端使用同一套内容，只调整排版与导航形态。白天/夜间主题、返回顶部和分享卡片
这些细节也一并补齐，目标是让“读一篇文章”这件事少受干扰。

## 让打磨成为日常

站点的价值在稳定的迭代，而不是上线当天的宣言。我们给自己定了个朴素的节奏：小改随发、
新增定期，导航与文档跟着使用反馈一路调整。

因此比起“敬请期待”，更希望听到“这里可以更好”。页面右下角的反馈与官方群组都欢迎——
把难用的地方告诉我们，改动能对得上真正的问题。

## 接下来

上线只是起点。接下来会继续补充社区介绍、使用指南和维护文档，也会把活动与项目的记录
整理成可长期引用的文章。第一次来可以先读[快速上手](/zh/docs/getting-started)；想参与
内容维护，可以直接看[编辑文章指南](/zh/docs/editing-guide)。

如果你发现旧链接失效、页面在某个设备上错位，或某段说明不够清楚，请把页面地址和截图发给
维护者。我们会把每一条能复现的反馈，变成下一次小改的依据。
