LKM 独立静态官网以阅读为主，不需要注册或登录。页面由 Markdown 内容构建，适合直接收藏、
分享和离线归档。

## 浏览内容

1. 从首页进入最新文章或新闻列表。
2. 使用页面语言入口在中文与英文内容之间切换。
3. 打开文章后，可直接复制浏览器地址分享；文章路径在发布后应保持稳定。
4. 新闻中的时间、报名方式或外部链接可能随活动变化，请优先查看同主题的最新公告。

## 反馈问题

反馈时请提供页面 URL、出现问题的文字或截图，以及你认为正确的内容。涉及历史事实的修改需要
来源或维护者确认；排版、翻译和失效链接可以直接提交修正建议。

## 隐私提示

静态页面本身不要求提交账号信息。跳转到外部网站、群组或社区服务后，应以目标服务的隐私政策
和使用条款为准。不要在公开反馈中粘贴密码、验证码、访问令牌或其他敏感信息。
